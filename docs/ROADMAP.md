# Roadmap

## MVP

- Projects, product requirements, suppliers, quotations
- Quotation currencies and manual exchange rates
- Required quantity vs. actual order quantity, SKU-level MOQ, pack/unit
  normalization
- Additional costs: fixed, percentage-based, freight, insurance, duty/customs,
  brokerage, bank/transfer fees, local transport, tax, discounts, surcharges
- Shared cost allocation
- Incomplete-quote detection
- Calculated landed total and effective landed unit cost per quotation
- Deterministic comparison explanations
- Local persistence (IndexedDB), autosave
- JSON backup/import
- Excel/Google Sheets clipboard paste, controlled CSV/XLSX support
- Turkish and English UI

## Later

- Automatic FX rate lookup
- Scenario analysis
- Quotation history / versioning over time

This list is intentionally short. It is not a feature wishlist — items move here
only when they are a genuine, considered candidate for after the MVP.
