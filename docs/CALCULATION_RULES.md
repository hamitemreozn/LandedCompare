# Calculation Rules

This document will be the source of truth for landed-cost calculation rules once
they are designed and approved.

## Phase 0 status

No calculation rules are defined or implemented yet. This file is a placeholder
so future calculation-engine phases (see [Implementation Plan](IMPLEMENTATION_PLAN.md),
Phase 2 — Core Calculation Engine and onward) have a known place to record
approved, reviewed financial rules — exchange rate handling, MOQ/pack
normalization, additional cost application (fixed, percentage-based, freight,
insurance, duty, brokerage, fees, local transport, tax, discounts, surcharges),
shared cost allocation, and incomplete-quote detection.

Nothing in this file should be treated as an implemented or approved rule until a
calculation phase explicitly adds it here.
